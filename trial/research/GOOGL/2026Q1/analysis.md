# Alphabet（GOOGL）2026Q1 分析

## Analysis

### 实际业绩
- 总收入：$109.9B（109,896M），同比+22%，恒定汇率+19%，连续第11个季度双位数增长。
- 净利润：$62.6B（62,578M），同比+81%；摊薄EPS $5.11，同比+82%。
- 营业利润：$39.7B（39,696M），同比+30%；营业利润率36.1%，同比扩大约2个百分点。
- 其他收入净额：+$37.7B，主要来自非上市股权证券的未实现收益。

### 分部表现
- Google Services：收入$89.6B，+16%。其中搜索及其他$60.4B（+19%）；YouTube广告$9.9B（+11%）；Google Network$7.0B（-4%）；订阅、平台和设备$12.4B（+19%）。分部营业利润$40.6B，利润率45.3%（去年同期42.3%）。
- Google Cloud：收入$20.0B，+63%，增长明显加速；分部营业利润$6.6B（去年同期$2.2B），利润率从17.8%升至32.9%。
- Other Bets：收入$0.4B（-9%），营业亏损扩大至-$2.1B（去年同期-$1.2B）。
- Alphabet层面活动（主要反映共享AI研发）：亏损扩大至-$5.4B（去年同期-$3.0B）。

### 管理层要点
- CEO Sundar Pichai表示，AI投资和全栈方法带动各业务：搜索AI体验推动使用量和查询量创新高；Google Cloud backlog环比几乎翻倍至超过$460B；付费订阅总数达3.5亿；Gemini Enterprise付费月活环比+40%；Waymo每周全自动驾驶超50万次；Gemini API直接使用每分钟处理超160亿token，环比+60%。

### 与预测/指引差异
- 无同期Preview，且本次新闻稿未提供2026Q2定量指引；来源中亦无可靠市场共识，故不做外部比较。

### 利润与现金观察
- 营业利润率提升主要来自Google Cloud利润率大幅改善（17.8%→32.9%）以及Google Services利润率上升至45.3%；同时共享AI研发（Alphabet-level）亏损扩大，部分抵消上述改善。
- 本季发行高级无担保票据，净募资$31.1B，用于一般公司用途；季度股息从$0.21上调至$0.22（+5%）。

### 下一季关注
- AI驱动的搜索收入+19%能否延续。
- Google Cloud backlog（>$460B）转化为收入的速度与利润率。
- AI研发及资本开支对营业利润率的影响；Alphabet-level亏损是否继续扩大。
- Google Network继续下滑的幅度；Other Bets亏损是否受Waymo扩张影响。
