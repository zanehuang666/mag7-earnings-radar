# Alphabet 2026 Q3 财报后分析

资料截止：2026-11-19。本目录没有在 Q3 发布前保存的同期 Preview，因此不进行事后补写的“前瞻复盘”。

## 主要结论

Cloud 收入和营业利润都大幅增长，但本季集团自由现金流为负。业务增长与投资回报需要分别判断。

## 财报结果

集团收入为 1,275.77 亿美元，同比增约 25%。Google Cloud 收入为 307.09 亿美元，同比增 103%；营业利润为 111.21 亿美元。搜索及其他广告收入为 633.50 亿美元，较上年同期的 565.67 亿美元增长约 12%。[Alphabet Q3 财报](https://www.sec.gov/Archives/edgar/data/1652044/000165204426000080/googexhibit991q32026.htm)

Cloud 增长包含 TPU 系统销售。公司没有披露这项销售的单独收入。因此，不能从分部增速推出传统云服务也增长了 103%。[Alphabet Q3 电话会](https://abc.xyz/investor/events/event-details/2026/2026-Q3-Earnings-Call-2026-Ujou16CTw9/)

## 利润和现金

本季经营现金流为 422.90 亿美元，购建物业和设备支出为 513.55 亿美元，自由现金流为负 90.65 亿美元。集团每股收益也受到股权投资未实现损失影响。只看 EPS，容易漏掉 Cloud 营业利润的改善。[Alphabet Q3 财报](https://www.sec.gov/Archives/edgar/data/1652044/000165204426000080/googexhibit991q32026.htm)

下一季要跟踪 TPU 系统交付、第三方算力成本对 Cloud 利润率的影响，以及资本开支何时带来持续现金回报。[Alphabet Q3 电话会](https://abc.xyz/investor/events/event-details/2026/2026-Q3-Earnings-Call-2026-Ujou16CTw9/)
