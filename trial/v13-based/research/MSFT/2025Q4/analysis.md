# MSFT 2025Q4（FY2026 Q2）财报分析

## 无同期 Preview

截至资料截止日，所附来源中没有本季度财报发布前的当期分析与预测；仅存在事后重建的历史资料稿，不可充当当时预测。因此本稿不做“原判断复核”，只基于官方新闻稿做实际结果分析。

## 实际结果

微软于 2026-01-28 发布截至 2025-12-31 的季度业绩（[官方新闻稿](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q2/press-release-webcast)）：

- 营收 813 亿美元，同比 +17%（固定汇率 +15%）；
- 营业利润 383 亿美元，同比 +21%（固定汇率 +19%）；
- GAAP 净利润 385 亿美元，同比 +60%；GAAP 摊薄每股收益 5.16 美元，同比 +60%；
- 非 GAAP 净利润 309 亿美元，同比 +23%（固定汇率 +21%）；非 GAAP 每股收益 4.14 美元，同比 +24%。

上年同期基准：营收 696 亿美元、营业利润 317 亿美元、GAAP 净利润 241 亿美元。汇率对营收报表的增量约 10 亿美元，故固定汇率增速比报告增速低约 2 个百分点。

**关键口径提示：** GAAP 与非 GAAP 的差异来自 OpenAI 投资。本季确认约 76 亿美元净收益（每股 1.02 美元）；上年同期为 9.39 亿美元净损失。剔除该影响后，净利润增速约 23%，显著低于 GAAP 表面的 60%。管理层称营收、营业利润、每股收益均超预期，但新闻稿未附独立市场共识数据，本稿无法独立验证。

## 分部表现

- **Microsoft Cloud** 收入 515 亿美元，同比 +26%（固定汇率 +24%），单季首破 500 亿美元；
- **生产力与业务流程** 341 亿美元，+16%；其中 Microsoft 365 商业云 +17%，Dynamics 365 +19%，LinkedIn +11%；
- **智能云** 329 亿美元，+29%；**Azure 及其他云服务收入 +39%**（固定汇率 +38%），为最强增长引擎；
- **更多个人计算** 143 亿美元，-3%，唯一负增长分部。Xbox 内容与服务 -5%，Windows OEM 与设备 +1%，搜索广告（剔除流量获取成本）+10%。

商业剩余履约义务（RPO）达 6250 亿美元，同比 +110%，反映 Azure 大额合同签署加速，是未来收入的领先指标。但新闻稿未拆分 Azure 中 AI 与非 AI 收入，AI 对增速与利润率的贡献无法从本稿来源单独验证。

## 现金与股东回报

季度内以股息和回购返还股东 127 亿美元，同比 +32%。新闻稿所核验文本未披露经营现金流与资本支出明细，待完整新闻稿或 10-Q 补充。

## 下一季要点

- Azure 39% 增速的延续性，以及 RPO 向收入转化节奏；
- OpenAI 投资公允价值波动对 GAAP 净利润的扰动；
- Xbox 内容与服务下滑是否触底，更多个人计算能否回正；
- 下一季度指引将在财报电话会议给出，本稿未使用新闻稿之外的预测数据。
