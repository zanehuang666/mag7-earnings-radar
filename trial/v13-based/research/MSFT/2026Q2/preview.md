# MSFT 2026Q2 财报前瞻（历史资料重建）

> 历史资料重建：本稿仅使用截至 2026-04-29 已公开的微软 FY2026Q3 新闻稿，未使用 2026-07-29 财报后信息；不暗示写于财报公布前。

## 一、结论

本稿推断，2026 日历 Q2（微软 FY2026Q4，2026 年 4—6 月）收入大概率延续双位数增长，但新闻稿未提供下季数字指引，本稿不预测具体收入或 EPS 区间。上季（FY2026Q3）总收入 828.86 亿美元，同比增长 18%；经营利润 383.98 亿美元，增长 20%；GAAP EPS 4.27 美元，增长 23%。管理层称上季业绩在收入、经营利润和 EPS 上均超预期。[微软 FY2026Q3 新闻稿](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q3/press-release-webcast)

## 二、上季基准与信号

- Azure 及其他云服务收入同比增 40%（固定汇率增 39%）；微软云收入 545 亿美元，增 29%（固定汇率 25%）。
- 商业剩余履约义务（CRO）增 99% 至 6270 亿美元。
- 公司披露 AI 业务年化收入运行率超 370 亿美元，同比增 123%。
- OpenAI 投资净损失税后影响仅 1400 万美元，远小于上年同期的 5.83 亿美元，是净利增速高于经营利润增速的主要原因之一。
- 分部：PBP 收入 350 亿美元（+17%）；Intelligent Cloud 347 亿美元（+30%）；MPC 132 亿美元（-1%）。MPC 中 Xbox 内容与服务收入降 5%，Windows OEM 和设备降 2%。

以上为已确认事实。

## 三、本季核心问题

1. Azure 能否维持约 40% 的同比增速。
2. AI 基础设施投入是否拖累利润率。上季经营利润率约 46.3%（按上述经营利润/收入计算），本季若保持或改善，增长质量更好。
3. MPC 是否会继续负增长，拖累整体收入增速。

## 四、正负预期差

可能的正面因素：AI run rate 高增和 CRO 订单转化为云收入；搜索广告（不含 TAC）增 12% 的动能延续。
可能的负面因素：Azure 增速放缓；汇率逆风（上季多项固定汇率增速低于报表增速）；OpenAI 投资损失扩大；Xbox 与 Windows OEM 持续疲弱。
以上为本稿推断，非公司指引。
