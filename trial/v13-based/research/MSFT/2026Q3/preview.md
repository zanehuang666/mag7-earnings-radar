# MSFT 2026Q3（FY27Q1）前瞻：历史资料重建

> 本稿为历史资料重建，写于资料截止日2026-07-29之后，并非当时真实发表的财报前预测；也未使用2026-10-28目标财报日之后的资料。资料仅来自微软FY26Q4官方新闻稿：[微软FY26Q4财报](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q4/press-release-webcast)。

## 结论

进入自然季2026Q3（微软FY27Q1），核心不是单季营收能否维持18%以上的同比增长，而是Azure在+43%的高增速上能否延续、AI/云需求转化为收入的同时利润率是否被资本开支和折旧挤压，以及More Personal Computing（MPC）板块是否继续拖累。由于来源未提供下一季量化指引，也没有可靠市场共识，本稿不给出EPS或营收点预测；相关数字需待公司电话会议或另行核实的共识资料。

## 上季基准（FY26 Q4，截至2026-06-30）

- 营收900亿美元，同比+18%（固定汇率+17%）；营业利润406亿美元，同比+18%；GAAP稀释EPS为4.81美元（+32%）；non-GAAP稀释EPS为4.74美元（+23%）。non-GAAP已剔除OpenAI投资相关净收益（EPS约0.07美元）。
- Microsoft Cloud收入593亿美元，同比+27%；Azure及其他云服务收入同比+43%；商业RPO同比+84%至6780亿美元。
- 分部：生产力和业务流程收入378亿美元（+14%）；智能云393亿美元（+32%）；更多个人计算129亿美元（-4%，固定汇率-5%），其中XBOX内容及服务收入-10%、Windows OEM与设备收入-7%。
- 上季EPS相对公司2026年4月指引有0.27美元净利好：包含32亿美元Anthropic投资相关收益、自愿退休计划支出低于预期，部分被XBOX减值和遣散费抵消。FY26全年Azure收入首次超过1000亿美元；Microsoft 365 Copilot付费席位超过3000万。

## 本季核心问题

1. Azure能否在高基数上维持接近43%的同比增速？
2. 商业RPO大增84%至6780亿美元，这些云/AI合同能否按节奏确认收入，并避免利润率大幅下滑？
3. MPC板块的负增长是否会因XBOX内容和Windows需求疲软而连续第二季拖累总体？

## 正负预期差

正向：

- 商业RPO同比+84%至6780亿美元，显示未来云收入能见度显著上升。
- Microsoft Cloud收入同比+27%、Azure收入同比+43%，AI相关需求仍在释放。
- Microsoft 365 Copilot付费席位超过3000万，说明AI增值功能在商业用户中持续渗透。
- FY26Q4调整后收入、营业利润和稀释EPS均超过公司4月指引。

负向/风险：

- 上季EPS的0.27美元净利好包含Anthropic一次性收益和自愿退休计划相关利好，FY27Q1不具备同口径基数。
- non-GAAP仅剔除OpenAI影响，不剔除Anthropic收益；若只按non-GAAP口径比较，仍可能高估经常性利润。
- MPC板块中XBOX内容及服务同比-10%、Windows OEM与设备同比-7%，可能继续压制整体增速。
- 来源未提供FY27Q1量化指引；任何被外界引用的“指引/共识”数字必须另行核实。

## 财报验证点

- Azure及其他云服务收入同比增速（GAAP与固定汇率）、Microsoft Cloud收入、商业RPO及Copilot付费席位变化。
- 营业利润增速是否与收入增速匹配，以及non-GAAP EPS中是否出现新的重大一次性项目。
- MPC分部：XBOX内容及服务、Windows OEM与设备、搜索广告（除TAC）的同比走势。
