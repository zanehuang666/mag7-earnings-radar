# 历史资料重建：美光 2026Q1（FY26Q2）财报前瞻

> 本稿为历史资料重建，仅以 [2025-12-17 官方新闻稿](https://investors.micron.com/news/press-release/2025/Micron-Technology-Inc--Reports-Results-for-the-First-Quarter-of-Fiscal-2026-12-17-2025/default.aspx)及其中指引为准；不含 2025-12-17 之后的信息，不代表当时实际发表的前瞻。本稿所称“本季”为 Micron FY2026 Q2，目标事件日期由任务定义为 2026-03-18。

## 结论
美光 FY26Q1 业绩发布时给出 FY26Q2 创纪录指引：营收 187 亿美元±4 亿，non-GAAP 毛利率 68%±1pct，GAAP EPS 8.19 美元±0.20，non-GAAP EPS 8.42 美元±0.20。若兑现，将大幅高于 FY26Q1 的 136.43 亿美元、56.8% 与 4.78 美元。来源中没有分析师共识或股价，因此本前瞻仅以公司指引为基准。

## 上季基准（FY26Q1，截至 2025-11-27）
- 营收 136.43 亿美元（环比 113.15 亿，同比 87.09 亿）；GAAP 净利 52.4 亿，non-GAAP 净利 54.82 亿。
- non-GAAP 毛利率 56.8%（上季 45.7%），non-GAAP 经营利润率 47.0%；各业务部毛利率均环比上升。
- 分部营收：Cloud Memory 52.84 亿（毛利率 66%），Core Data Center 23.79 亿（51%），Mobile & Client 42.55 亿（54%），Automotive & Embedded 17.2 亿（45%）。
- 经营现金流 84.11 亿；调整后自由现金流 39.06 亿，资本开支净额 45.05 亿。

## 本季度核心问题
1. AI/数据中心组合能否继续支撑毛利率？Cloud + Core DC 合计约 76.6 亿美元，占总营收约 56%；指引毛利率环比再升约 11pct，需观察 HBM 等对分部利润的拉动。来源未披露 DRAM/NAND 各自利润。
2. 营收环比增约 37% 的结构是否可信：指引中点 187 亿美元较上季增加约 50 亿美元；需验证是数据中心拉动还是普涨。
3. 现金创造与资本开支平衡：FY26Q1 调整后自由现金流转强，但资本开支仍高；FQ2 指引未给 FCF。

## 正负预期差
- 正向：若营收贴近上限（约 191 亿）、non-GAAP EPS 贴近 8.62 美元且毛利率贴近 69%，将高于指引中枢。
- 负向：若营收贴近下限（约 183 亿）或毛利率贴近 67%，则低于指引中枢；AI 需求或库存调整在来源中未量化。

## 财报验证点
- FY26Q2 营收、GAAP/non-GAAP 毛利率、EPS、经营现金流与调整后 FCF。
- Cloud Memory 与 Core Data Center 的营收和毛利率是否继续环比扩张。
- 资本开支、还债与回购对现金余额及每股收益的影响。
