# 历史资料重建｜三星电子 2026Q2 预览（资料截止：2026-04-30）

本文是历史资料重建，不是财报公布前实际写成的预测；内容只使用三星电子于2026年4月30日发布的2026Q1业绩稿中已公开的信息，不使用2026Q2财报发布后的任何资料。

## 一、结论

三星电子在2026Q1创下合并收入133.9万亿韩元、合并营业利润57.2万亿韩元的历史单季新高。进入2026Q2，公司给出的主要口径是：存储需求仍受AI基础设施扩张支撑，公司将交付首批HBM4E样品；MX业务进入淡季，预计收入环比下降、同比上升；非存储业务中，Foundry计划先进节点产线满产，SDC主打高端，Harman预期随汽车供应增加而改善。本稿未在来源中找到Q2合并数字指引，故不另做外部预测。

## 二、上季基准

- 合并：收入133.9万亿韩元，环比+43%；营业利润57.2万亿韩元；均为单季历史新高。
- DS部门：收入81.7万亿韩元，营业利润53.7万亿韩元；存储业务因ASP上升、AI高附加值产品（HBM4、SOCAMM2）和行业性存储涨价创单季收入与利润新高。
- DX部门销售环比+19%，由新旗舰手机发布带动；MX与Networks业务收入38.1万亿韩元，营业利润2.8万亿韩元。
- SDC：收入6.7万亿韩元，营业利润0.4万亿韩元；VD与DA：收入14.3万亿韩元，营业利润0.2万亿韩元；Harman利润下滑。

## 三、本季核心问题

1. 存储业务：Q1收入与利润均创纪录，Q2能否靠AI需求、ASP和HBM4E送样维持增长，还是进入高基数下的消化期？
2. MX业务：旗舰发布效应消退后，公司预计收入环比下降、同比上升；关注淡季中营业利润率能否保持个位数盈利及A系列对出货的支撑。
3. 非存储业务：System LSI扩大SoC与传感器销售、Foundry满产与HBM4 base die供应、SDC高端产品、Harman汽车供应回升，能否缩小DS与其他业务的利润差距。

## 四、正负预期差

正向：若AI基础设施扩张强于公司预期，存储ASP和HBM4E验证进度可能推动DS超预期；Foundry先进节点利用率提升、MX成本优化好于预期也会形成上行空间。

负向：若存储价格因供给缓解而回落，或HBM4E样品进度延后，DS利润可能环比回落；MX淡季叠加成本压力与关税；SDC中小尺寸需求疲弱；Harman费用压力持续。

## 五、财报验证点

1. DS分部收入与营业利润，存储ASP环比、DDR5/SOCAMM2占比、HBM4E样品表述。
2. MX收入环比/同比、营业利润率、A系列与旗舰销量。
3. Foundry先进节点利用率与HBM4 base die供应表述；SDC高端占比与8.6G IT OLED进度；VD体育赛事需求；DA空调与新品；Harman汽车供应。
4. 公司对H2的服务器内存、agentic AI、2nm/1.4nm、折叠屏等业务的更新指引。
